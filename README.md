# Local AI Lab

Prototype expérimental : 10 fiches locales fictives conçues pour tester la découverte et la compréhension par les moteurs et assistants IA.

## Objectifs
- pages HTML indexables
- JSON-LD LocalBusiness
- sitemap.xml et robots.txt ouverts aux crawlers
- API JSON publique
- llms.txt + ai-index.json
- couche d'intentions utilisateur

## Sécurité / vérité
Toutes les fiches sont fictives et explicitement marquées DEMO. Elles ne doivent pas être interprétées comme de vrais commerces.

## Déploiement
Déployer sur Vercel et définir `NEXT_PUBLIC_SITE_URL` sur l'URL publique finale.
